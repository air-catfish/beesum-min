# v0.2.0

First public release of **beesum-min**: a transcript-first YouTube summarizer
library and CLI, MIT-licensed.

## Packages

| Package | Version | What it is |
| --- | --- | --- |
| `Beesum.Core` | 0.2.0 | Models, contracts, WebVTT parser, yt-dlp service, LLM providers, pipeline, storage |
| `Beesum.Testing` | 0.2.0 | In-memory doubles and `AddBeesumTesting()` for hermetic tests |
| `beesum-min` (tool) | 0.2.0 | The command-line host |
| `beesum-mcp` (tool) | 0.2.0 | MCP stdio server for agents |

## Highlights

* **Public, documented Core API.** `AddBeesum(Action<BeesumOptions>)` +
  `IOptions<BeesumOptions>`, optional `ILogger<T>` integration, and
  `ISummarizerPipelineFactory` for run-time provider selection. Implementations
  are internal; interfaces, models, and DI are the contract.
* **Summary metadata.** `SummaryResult` reports `ProviderId`, `ModelName`,
  `Usage` (token counts), and `Duration`.
* **JSON output.** `beesum-min --json` emits one stable object for scripts; see
  [docs/json-output.md](../json-output.md).
* **Trusted Publishing.** nuget.org publishes through GitHub OIDC; no long-lived
  NuGet API key is stored.
* **Clips and saves.** `--from/--to`, `--save-vtt`, and `--save-transcript`
  turn a long video into a local note.
* **Timecodes and mindmaps.** `--timestamps` keeps `[hh:mm:ss]`; `--format mindmap` returns Mermaid.
* **MCP.** `beesum-mcp` exposes the pipeline as two tools for Claude/Cursor/other
  MCP clients.
* **Chunking.** Long transcripts are split and reduced with map-reduce; usage and
  duration are summed across calls (`--chunk-tokens`, `--no-chunk`).
* **Beesum.Testing.** `InMemory*` stores, yt-dlp/parser/process/HTTP doubles, so
  consumers can test without disk, network, yt-dlp, or Ollama.
* **Transcript-first privacy.** The default `transcript-only` provider never sends
  the transcript anywhere; `ollama` talks only to the local instance.

## Install

```powershell
dotnet tool install -g beesum-min
dotnet add package Beesum.Core
```

## Known limitations

* The API follows `0.x`: names and shapes may change before 1.0.
* No chunking of long transcripts; very long videos may exceed the model context.
* The CLI exposes Ollama and `transcript-only`; the OpenAI-compatible provider is
  library-only for now.
* `ITranscriptCache` and `ISummaryHistory` are contracts, not yet wired into the
  pipeline.
* Docker images are built and published by CI; the local machine used for this
  release has no Docker daemon.
* `dotnet test` is unreliable on some locked-down Windows machines; run the test
  projects with `dotnet run` there (see the troubleshooting page).
