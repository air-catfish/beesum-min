# v0.2.3

## Added

- MCP `get_transcript` for clients that summarize themselves; supports
  `start`/`end` clipping and `offset`/`limit` pagination.
- MCP tool annotations and versioned `.mcp/server.json`.

## Changed

- yt-dlp receives the URL after `--`; non-http(s) URLs are rejected by the service.
- Built-in prompts explicitly mark the transcript as untrusted data.
- Smoke fixture moved to `samples/demo/smoke.vtt`.
