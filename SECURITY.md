# Security

Report vulnerabilities through **GitHub → Security → Advisories**. Do not open a
public issue.

Include the affected version, a minimal reproduction, and the impact. Expect an
acknowledgement within 72 hours and a fix or plan within 30 days.

Only the latest `0.x` version is supported. API keys are read from environment
variables, transcripts stay local with `transcript-only`, and yt-dlp arguments are
passed as a list, not a shell string.
